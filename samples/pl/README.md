# Synthetic sample letters (Poland, residence permit)

Fully synthetic. Names, addresses and case numbers are invented; offices are real
voivodeship offices only for realism. Amounts and deadlines are what the *letter* says,
not verified facts: checking them against official sources is PaperTrail's job.

- `NN-*.txt` — letter text (ground truth for OCR).
- `NN-*.expected.json` — fields extraction should find (for evals).
- `NN-*.jpg` — rendered "phone photo", generated by `scripts/render_samples.py`.
